
# Python Mastery Assignment

This repository contains 12 Python practice parts and a School Manager final project.

1. Install Python 3.11 or newer.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Run the School Manager: `python main.py`
4. Run the tests: `python -m pytest -v`
5. Run an individual part: `python parts/part01_variables.py`

The School Manager supports student records, marks, report cards, class rankings and JSON persistence.
